# Visuels de la page Bataille Navale

Déposer ici de vraies captures du jeu (jpg, png ou webp). Elles apparaissent automatiquement d'après leur nom de fichier.
Sans image, la page affiche des emplacements aux couleurs de la mer.

| Fichier | Où il apparaît | Format conseillé |
|---|---|---|
| `hero-1`, `hero-2`, `hero-3` | diaporama du bandeau (un seul suffit) | 16:9, 1920 px de large |
| `plateau` | « Un plateau, une flotte, un arsenal » | 16:10, capture du plateau 3D |
| `editeur` | grande capture de l'éditeur de cartes | 16:9 |
| `editeur-placement`, `editeur-cases-bloquees`, `editeur-export` | les trois étapes sous l'éditeur | 4:3 |

Le bouton « Jouer maintenant » apparaît quand `GAME_URL` est renseigné dans `src/data/bataille.js`.
Les extraits de code de la page viennent du dépôt du jeu : `src/data/bataille.code.js`.
