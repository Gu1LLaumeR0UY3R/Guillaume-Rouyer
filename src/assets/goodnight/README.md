# Visuels de la page Goodnight

Déposer les images ici (jpg, png ou webp). Elles apparaissent automatiquement d'après leur nom de fichier.
Sans image, la page affiche des emplacements neutres.

| Fichier | Où il apparaît | Format conseillé |
|---|---|---|
| `hero-1`, `hero-2`, `hero-3`, `hero-4` | diaporama du bandeau (un seul suffit) | 16:9, 1920 px de large |
| `desktop` | maquette ordinateur | capture de la version web, 16:10 |
| `mobile` | maquette téléphone | capture de l'application mobile, 9:19 |
| `calendrier`, `tableau-de-bord`, `notifications`, `validation` | « Les écrans qui comptent » | 4:3 |

Utiliser de vraies captures du produit. Les images doivent rester légères (WebP ou JPEG optimisé).
